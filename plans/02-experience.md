# 页面、视觉与交互设计

## 设计方向

整体像一个轻巧的宠物创作工作室。暖白画布、深色文字和紫色主按钮，以宠物照片和视频预览承担视觉重点。圆角和少量爪印装饰营造趣味，但不使用大面积霓虹和持续跳动效果干扰上传、选段和预览。

桌面端优先展示“输入素材 / 输出结果”的关系；移动端按照片、舞蹈、选项、生成顺序纵向完成。所有用户界面默认中文。

## 视觉规范

| 项目 | 设计值 |
| --- | --- |
| 页面背景 | #F7F5F0 暖白 |
| 卡片 | #FFFFFF，边框 #E4E1EA |
| 主文字 / 次文字 | #20202A / #5F606E |
| 主色 / 悬停 | #6D28D9 / #5B21B6 |
| 浅强调底 | #F0E8FF，搭配深紫文字 |
| 成功 / 错误文字 | #166534 / #B91C1C，并附图标与文字 |
| 字体 | 系统中文无衬线，英文字体跟随系统，首版无需外部字体请求 |
| 字号 | 页面标题 32–40 px；区块标题 20–24 px；正文 16 px；辅助 14 px |
| 间距 | 以 4 px 为基础，常用 8 / 12 / 16 / 24 / 32 |
| 圆角 | 输入框 12 px；卡片 20 px；主展示区 24 px |
| 阴影 | 轻微单层，仅用于悬浮元素和主预览卡 |
| 动效 | 150–220 ms 状态过渡，遵循减少动态效果设置 |

颜色为设计起点，实施时验证文本、焦点、禁用态和错误态的实际对比度；普通正文目标至少 4.5:1。不能只靠颜色说明状态。

## 页面地图

| 路径 | 页面职责 |
| --- | --- |
| / | 首页兼创作台，直接上传，无需多次跳转 |
| /jobs/[id] | 排队、生成过程及失败恢复；成功后展示结果 |
| /library | 我的作品，含运行中、已完成、失败和过期状态 |
| /privacy | 素材使用、供应商传输及保留期限说明 |
| /terms | 使用条件、素材授权和内测额度说明 |

登录、删除确认、用量确认采用弹层；窄屏变为底部抽屉。作品详情复用任务页，不另设重复结果页。

## 首页与创作台

顶部：左侧爪印符号与“爪爪舞台”，右侧“我的作品”、应用剩余额度和头像；未登录显示“登录”。首屏标题“让你家毛孩子，跳上同一支舞”，副标题“上传或粘贴宠物素材链接，选一段舞蹈，做成专属小短片”。OpenRouter credit 消耗在任务详情中单独展示，不与应用额度混用。

内容最大宽度约 1200 px，左右区块约 60:40；≥1024 px 用双栏，768–1023 px 用单栏并加宽预览，<768 px 保留 16 px 边距。桌面预览可以粘性定位，但高度不超过可视窗口。

示例必须标明“示例效果”，最好来自实际可用模型；在模型尚未验证的设计稿中显示占位图和“效果示意，待实测”，不能将示意当作真实产物。首版无需 AI 生成品牌图片或编写原型代码。

## 上传、导入与选段

- 图片区支持拖拽和可键盘触发的文件选择；上传后按容器完整显示，用户可检查头部和身体，不默认裁掉四肢。
- 宠物区的本地上传与素材链接均支持图片及视频；宠物视频显示选帧时间轴，用户确认代表帧后进入后续流程。舞蹈参考是另一份独立素材，两个区块不能混淆。
- 参考视频区用页签切换“上传视频 / 视频链接”，切换不立即丢弃旧输入；真正采用新输入时才替换。
- 宠物链接输入占位：“粘贴图片或宠物视频的 HTTPS 直链”；舞蹈链接占位：“粘贴可直接下载的视频 HTTPS 链接”。导入按钮独立触发，避免每次输入就抓取。
- 导入中显示“正在检查视频…”；成功后显示真实时长和文件大小，超限时就地报错。
- 选段同时提供拖动手柄、开始时间输入、结束时间输入，键盘可操作；移动端触点至少 44×44 px。
- 视频选段仅预览被选区间，可循环播放；参考视频与生成结果不自动同时播放。
- 素材错误紧贴控件显示，不只发短暂 toast。失败时保留其他已完成输入。

## 模型选择

创作台展示两个独立、可搜索的下拉菜单，移动端使用可搜索底部抽屉：

- “整理提示词的模型”：OpenRouter Models → Text 输出分类 → Gemini 系列。辅助文案“由所选 Gemini 优化基础提示词”。
- “生成视频的模型”：OpenRouter Models → Video 输出分类。辅助文案“仅显示视频输出模型，实际可用性取决于素材兼容与接入状态”。

选项显示官方名称、准确 ID、可确认的能力及估价单位；不填造示例型号或统一折算价格。默认显示“请选择模型”，可恢复仍有效的上次选择，但不自动用新模型替换失效选择。不兼容项保留并禁用，说明如“不支持参考视频”或“尚未完成接口验证”。

加载、空列表、加载失败、缓存待刷新及选择已失效都有独立状态和重试入口。Video 空列表提示“OpenRouter 当前未返回可用的视频输出模型”，禁止提交；不把视频理解模型充作生成选项。切换模型保留素材，刷新规格并作废旧报价；参数冲突时要求重新选择，不静默裁剪或付费重跑。

详细筛选、缓存和校验规则见模型选择设计。

## 提交与进度页

确认摘要包含宠物缩略图、选段时间、两个所选模型名称和 ID、输出画幅和时长、当前能力说明、预计额度和素材期限。模型未选定、失效或估算缺失时禁止提交，并显示可重试原因。

主按钮状态：“添加两份素材” → “生成跳舞视频” → “检查素材中…” → “确认并生成”。点击后立即防重复；服务端仍用幂等控制。

生成阶段依次显示：

1. 检查素材：文件安全、选段和质量校验。
2. 理解动作并优化提示词：通过 OpenRouter 调用用户在下拉菜单选择的 Gemini 再加工基础提示词；失败时不跳过此步骤、不自动换型号。
3. 排队中：已被供应商接收但尚未开始执行。
4. 正在生成：供应商执行视频生成。
5. 处理视频：取回、转码与可播放性检查。
6. 完成：显示视频与下载操作。

素材检查可以在最终确认前完成；状态映射按实际后端阶段展示，不强制所有任务都重复该步骤。进度条采用阶段式，不显示推测的 87%。供应商没有进度时显示“正在生成，已等待 1 分 20 秒”；只有实测分布足够时才给等待范围。

长任务提示“可以离开，稍后在我的作品查看”。首版通过作品列表恢复，不承诺邮件或推送通知。刷新后从服务端恢复，页面本地计时不作为任务事实。

## 结果与作品页

结果页以竖屏播放器为中心，右侧显示输入缩略图、参数、生成时间和到期日。主操作“下载视频”，次操作“用同样素材再生成”“创建新作品”，删除放入更多菜单。

输入尚在保留期内才可直接再生成；原素材已过期则提示重新上传。再生成先展示新的消耗摘要，不覆盖旧作品。

作品页为响应式卡片：缩略图、状态、创建时间、时长；提供全部 / 进行中 / 已完成 / 失败筛选。空态“第一支宠物舞，等你来创作”，按钮“开始制作”。失败卡提供原因和重试，过期卡说明文件已清理，不能展示仍可下载的假入口。

结果页下方增加“用量与费用”面板：默认显示 OpenRouter 总 token 和实际 credit 消耗，展开后显示输入/输出 token、每次分析和提示词再加工调用、实际模型、结算时间。重试及修复调用计入本任务总消耗，失败任务也可查看已产生费用。

提示词模型与视频模型按阶段分别显示实际费用、模型和结算来源；两者都由 OpenRouter 结算时分别计入明细并去重汇总 OpenRouter credit。不返回 token 的视频调用显示“不适用/未提供”，不能用时长伪造 token。任何经确认的独立结算费用及应用额度单列，不拼成无单位的“总 credit”。等待上游费用返回时显示“费用结算中”；字段不支持时显示“暂不可获取”，都不能显示为 0。没有发生调用才可明确显示 0。用户无需阅读后台日志即可看到明细。

## 移动端与无障碍

- 素材区按顺序纵向排列，预览放在提交区之后；生成时跳转专属任务页，避免进度卡藏在屏幕下方。
- 底部固定生成按钮仅在输入阶段显示，预留安全区且不遮挡表单错误和最后一项内容。
- 所有按钮具备可见焦点，页签、弹层、播放器和时间选择器支持键盘；弹层关闭后焦点回到触发按钮。
- 阶段变化使用温和的屏幕阅读器播报，不逐秒播报计时；错误总结可聚焦。
- 图片用描述性替代文本，视频提供文字状态；页面不自动播放有声内容。

## 核心文案

| 情况 | 建议文案 |
| --- | --- |
| 图片建议 | “选一张只有它、脸部清楚的照片，全身照更容易跳出好动作。” |
| 网页链接 | “暂不支持解析这个网页。请上传你有权使用的视频文件。” |
| 多主体参考 | “画面里有多个舞者，动作可能难以对应。建议换成单人片段。” |
| 模型不可用 | “当前生成服务暂不可用，素材选择已保留，请稍后重试。” |
| 内部失败 | “这次没能生成成功。额度处理状态见下方，可稍后重试。” |
| 待确认扣费 | “供应商结果仍在确认，暂未返还额度；不会自动再次生成。” |
| 过期提示 | “作品将保留至 {日期}，喜欢的话记得下载。” |
| 删除说明 | “删除后立即停止访问，后台将清理相关文件。已产生的生成费用不退回。” |
