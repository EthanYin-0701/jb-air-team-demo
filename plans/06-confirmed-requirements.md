# 追加要求核对与明确约束

## 核对结论

原设计未完整包含这三项：提示词组织未指定 Gemini；素材支持宠物照片及舞蹈视频，但缺少宠物视频和图片 URL；token 与费用只有后台记录，没有面向用户的结果页明细。现已同步补充产品、交互、AI、架构和验收设计，本次仍不写应用代码。

## 1. 基础提示词必须经指定 Gemini 再加工

必经链路：**素材检查与理解 → 版本化基础提示词 → OpenRouter 调用用户指定的 Gemini 3.7 Flash 再加工 → 服务端校验 → 将最终提示词与素材提交给视频生成模型。**

基础提示词包含宠物外观、参考动作概括、风格、画幅及身份保持约束。Gemini 将其整理成目标视频模型可接受的最终提示词；服务端按该模型能力校验长度、必要字段与约束，不让用户素材覆盖系统规则。

每次生成记录基础模板版本、再加工调用 ID、实际模型 ID 和最终提示词摘要，以证明视频模型收到的是再加工结果。完整提示词只作短期私密任务数据，不进入普通日志。

再加工失败时停止下游视频生成，不直接使用基础提示词，也不静默换模型。修复和重试产生的消耗一并展示。

**名称核验待办：**本次尝试联网检索及读取 OpenRouter 模型目录，但工具不可用、直接请求被代理拒绝，无法确认“Gemini 3.7 Flash”的存在性、准确名称或 API ID。此名称按用户指定要求保留，不将其写成已验证模型；实施前核验，若无对应模型需用户确认替代型号。

## 2. 图片与视频均支持本地和 URL

| 素材角色 | 本地上传 | HTTPS 媒体 URL | 如何用于生成 |
| --- | --- | --- | --- |
| 宠物图片 | 支持 JPEG、PNG、WebP | 支持图片直链 | 作为宠物身份图 |
| 宠物视频 | 支持 MP4、MOV、WebM | 支持视频直链 | 用户选择清晰代表帧作为身份图；支持时可加分析帧 |
| 参考舞蹈视频 | 支持 MP4、MOV、WebM | 支持视频直链 | 选择短片段，作为舞蹈动作参考 |

宠物素材与舞蹈参考是两个独立角色，可混合来源，例如本地宠物视频 + 网络舞蹈视频、网络宠物图片 + 本地舞蹈视频。

支持“上传宠物视频”不等于承诺任意生成模型可直接接收整段宠物视频。首版通过用户选帧兼容身份图输入；若供应商支持原始宠物视频，再单独验证后开放。用户能在生成前检查实际采用的身份图。

URL 资源先安全导入私有存储，再按与本地素材相同的规则校验、解码和处理。网页分享链接、需登录资源和不可下载链接提供明确失败提示及本地上传入口，不默认为支持任意视频网站解析。

大小、时长与质量限制沿用产品方案。无论来源是什么，均执行归属校验、SSRF 防护、超时与资源限制及到期清理。

## 3. 生成完成后展示 token 与 credit 实耗

结果页提供可展开的“用量与费用”面板，失败及取消任务也可查看已经产生的消耗。

| 展示项 | 定义 |
| --- | --- |
| OpenRouter 输入 token | 当前任务所有真实 OpenRouter 调用的输入 token 合计 |
| OpenRouter 输出 token | 当前任务所有真实 OpenRouter 调用的输出 token 合计 |
| OpenRouter 总 token | 按上游计数语义核验后汇总的总量；缺失项不猜测 |
| OpenRouter 消耗 credit | 根据任务关联调用的实际扣费数据及经核实单位显示，不使用应用额度代替 |
| 调用明细 | 素材分析、Gemini 再加工、修复与重试分别列出模型、token、实际费用和状态 |
| 视频生成费用 | 另行列出视频供应商及其货币或 credit 单位；不冒充 OpenRouter 消耗 |
| 应用额度 | 单列预留、结算、返还及净消耗，与 OpenRouter credit 明确区分 |
| 结算状态 | 结算中、部分已确认、已确认、暂不可获取，并显示更新时间 |

界面以任务数据为准，不显示应用共用 OpenRouter 账号的全局余额。无需用户拥有供应商账号或查看后台日志。

### 统计规则

- 每一次 OpenRouter 调用保存唯一调用 ID，重试、修复和不同步骤全部关联同一生成任务；重复回调、轮询和结算补录不重复累加。
- token、费用来自上游实际响应或经官方核实的调用明细查询；供应商字段和接口尚待实施前核验。
- 不用整个账号余额前后差作为单任务成本，避免并发、充值和其他任务干扰；不拿估价冒充实际扣费。
- 不假定所有 token 类别互斥。缓存、推理等分项只有在计数语义确认后展示，不与总量重复相加。
- 金额保存数值、币种或 credit 单位及精度。若只能获得货币金额，必须核实官方换算后才能同时标为 credit，不能自定比例。
- 费用未知保存为空并显示状态；只有确认未消耗时显示 0。部分调用未结算时显示已确认小计，不称完整实耗。
- 视频完成后先开放预览与下载，费用可稍后补齐；后台在有界对账窗口内查询，并自动更新页面。
- 视频失败也可能已经产生 Gemini 费用；实际供应商消耗与产品退款分开显示，不能因返还应用额度把实际消耗归零。
- 只有同一币种且数据完整时才能给出总金额，OpenRouter credit、其他供应商 credit 和应用额度不能直接相加。

## 追加验收

1. 在调用追踪中确认视频模型接收的提示词来自指定 Gemini 的成功输出；中间失败绝不调用付费视频生成。
2. 宠物图片、宠物视频、舞蹈视频的本地与 URL 六类输入均可完成各自流程，并支持混合来源。
3. 结果页无需后台权限即可看到实际输入/输出/总 token 与 OpenRouter credit，能展开每次调用。
4. 双击、重试、重复回调、费用延迟、失败及取消时，数据无重复、无伪零、费用与退款可区分。
5. 用户不能读取其他用户的任务费用、供应商密钥或应用账号余额。
