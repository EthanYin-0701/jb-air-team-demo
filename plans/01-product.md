# 产品需求与范围

## 目标用户与价值

面向希望制作、分享宠物趣味短视频的普通用户。用户不需要写提示词、选模型或理解视频参数，只需提供宠物照片和舞蹈参考。结果必须容易辨认出自己的宠物，并能看出与参考舞蹈的关联。

首版走轻拟人化方向：允许猫狗直立及夸张摆动，保持宠物面部与毛色。UI 不承诺真实动物骨骼可完整复现人体动作。

## MVP 范围

| 包含 | 首版边界 |
| --- | --- |
| 宠物照片 | 单张、单主体，猫狗优先；预览、替换、质量提示 |
| 舞蹈参考 | 本地上传，或服务端安全抓取可下载的 HTTPS 视频直链 |
| 视频选段 | 用户选择 3–8 秒；默认 5 秒；最终时长还受供应商能力限制 |
| 风格 | 「保留原貌」「可爱卡通」两种；是否真正可用以模型测试为准 |
| 构图 | 默认竖屏 9:16，支持 1:1；模型不原生支持时须测试裁切效果 |
| 生成 | 提交前展示时长、画幅、预计消耗；有排队、阶段状态和失败恢复 |
| 结果 | 浏览器预览、下载 MP4、再生成、删除 |
| 历史 | 最小登录与“我的作品”，可重新进入未完成任务 |

不包含：任意社交平台解析、平台登录态抓取、多宠物、长视频、真人换脸、动作编辑器、训练用户专属模型、公开社区、自动发布和付费套餐。暂不提供公开分享链接，避免首版引入公开素材托管与审核体系。

照片及参考视频可先本地预览，提交前才要求登录；默认采用邮箱一次性验证码，通过成熟认证服务实现，供应商实施前确定。邀请码和账号额度用于控制内测成本。

## 主流程

1. 进入创作台，看见示例和两块素材区，不强制先登录。
2. 上传宠物照，显示裁切预览和清晰度提示；提醒单只宠物、脸部无遮挡、全身照更利于动作生成。
3. 上传舞蹈视频，或粘贴直链。解析成功后显示缩略图、时长、选段滑块及预览。
4. 选取片段、风格和画幅。UI 显示“轻拟人化，保留宠物主要特征”的效果说明。
5. 点击“生成跳舞视频”，未登录则在弹层中完成认证，保留当前本地选择。登录后上传素材并完成服务端检查。
6. 根据实际素材和模型能力展示最终确认摘要与消耗估算；用户确认后创建任务并扣留一次生成额度。
7. 页面显示真实任务阶段，允许离开，任务继续执行。创作台和作品页都可恢复状态。
8. 完成后自动进入结果页，用户预览、下载，或基于原素材发起新任务。

确认摘要是产品内正常的费用确认，不是本次文档工作需要用户授权。

## 输入与输出约束（产品目标，非供应商既定限制）

| 项目 | 初始约束 | 处理方式 |
| --- | --- | --- |
| 图片 | JPEG、PNG、WebP；≤15 MB；长边建议 ≥1024 px | 服务端解码校验，统一方向、清除元数据、压缩生成分析副本 |
| 视频 | MP4、MOV、WebM；≤100 MB；总长 ≤60 秒 | 真实解码探测，限制分辨率和帧率，转成内部统一格式 |
| 参考片段 | 3–8 秒，默认 5 秒 | 服务端裁剪；片段上限由能力配置取产品与模型的较小值 |
| 画面 | 单主体、身体较完整、运动清晰 | 主体识别仅作辅助；遮挡、多主体、过暗时给明确建议 |
| 输出 | 可播放 MP4，目标 720p、竖屏、无声 | 以供应商实测能力定义可售规格；失败时不输出假成功 |

不同模型支持固定时长时，UI 只开放对应选项，并在确认前说明补帧、截断或裁切策略。禁止生成完成后才告知规格缩水。

默认输出无声。预览参考视频时默认静音，可手动开启；首版不自动复制舞曲或从网页提取音乐。未来可增加用户明确授权的音轨合成。

## 产品状态与恢复

| 场景 | 用户可见行为 |
| --- | --- |
| 平台分享链接 | 提示“此链接是网页，暂不支持直接读取。请上传你有权使用的视频文件。” |
| URL 需登录、已失效或禁止抓取 | 导入失败并保留链接，提供上传入口 |
| 图片可能不适合 | 说明原因，允许替换；质量建议可继续，危险或无法解码的输入阻止提交 |
| 没有可用模型或额度不足 | 禁止发起付费生成，展示可恢复原因 |
| 任务排队 | 显示排队中和真实等待时间，不伪造百分比 |
| 模型失败 | 展示友好原因；按账务结果返还或说明额度，重试前重新报价 |
| 效果不满意 | 保留原结果；“再生成一次”说明会产生新的消耗 |
| 离开页面或刷新 | 登录后从作品列表恢复服务端任务 |
| 删除 | 先隐藏并停止提供访问，异步清理素材、产物和供应商副本（若支持） |

首版只承诺在进入供应商执行前取消。供应商已执行时是否可取消、是否收费取决于实测能力，页面明确显示状态，不能把“停止等待”当作取消成功。

## 成功标准

- 从进入页面到准备提交，首次用户能在 2 分钟内完成素材选择（不包含视频准备时间）。
- 核心质量门槛：宠物身份可辨、动作有参考关联、无严重身体崩坏；评价方法见 AI 验证方案。
- 所有任务都有最终状态或可追踪的人工排查入口，无无限转圈。
- 每一次提交、供应商调用、扣费与退款均可追踪，双击与重试不重复计费。
- 生成耗时与成本先在验证阶段测量，再公布范围；当前不承诺固定秒数或单次价格。

## 素材保留

默认原始素材保留 24 小时；生成作品保留 7 天；页面显示到期日期并提醒下载。失败任务也按策略清理。精简任务和账务记录保留 30 天，去除素材链接、完整提示词和个人内容；超出期限的财务保留要求在上线前确认。

下载链接 5 分钟有效，可在作品未过期时刷新。原始素材已过期时，“再生成”需重新上传，不能承诺永久复用。用户可提前删除，不以后台任务仍在运行作为继续公开访问素材的理由。
