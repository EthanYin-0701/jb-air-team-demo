# 实施顺序、验收与待决策项

本文件是后续开发计划，本次不执行安装依赖、初始化 Next.js、创建接口、调用付费模型或部署。

## 阶段 0：验证核心能力

产物：供应商能力矩阵、真实输入输出样例、人工评分、单次成功成本与耗时统计、数据及许可结论。

官方定义核验已完成：output_modalities=text/video、arch=Gemini、通用分页、专用视频目录及原生视频接口，详见接口核验文档。下一步在可访问网络和配置账号后实测实时响应、权限、路由与费用，再完成 AI 两轮验证；不重复将已确认参数列为未知。至少验证一个可选 Gemini 和一个 Video 模型，确认提供方没有忽略参考视频，并通过猫狗质量门槛。若只能做灵感生成需先收缩承诺；Video 为空时阻止生成，不填入外部目录选项。

退出条件：选定至少一个可用视频模型及 OpenRouter 分析模型，明确支持规格、成本上限、商业使用和删除策略。能力不达标时停在实验阶段，而非继续搭建一个无法兑现核心效果的产品。

## 阶段 1：确定体验与视觉

产物：首页、素材上传、直链导入、视频选段、两个模型下拉菜单及加载/空态/不兼容状态、登录、费用确认、排队、生成、成功、失败、我的作品和过期状态的高保真设计。

覆盖桌面与移动布局，确定品牌名、色彩、按钮层级及无障碍规范。演示素材必须有来源说明，尚未验证的效果标记为示意。可先做静态设计稿，待用户要求开发时再建立交互原型。

退出条件：用户可从页面理解“上传什么、如何选舞蹈、花多少、等多久、哪里下载”，所有关键失败均有可恢复入口。

## 阶段 2：搭建最小端到端流程

产物：Next.js 创作台、认证、私有存储、上传与视频处理、持久任务、真实模型调用和结果下载。

优先实现本地宠物图片与舞蹈视频上传，把“素材 → 选段 → 报价 → Gemini 提示词再加工 → 异步生成 → 下载与用量明细”走通，再加入宠物视频选帧和网络直链导入。最终 MVP 必须支持宠物图片、宠物视频、舞蹈视频各自的本地与 URL 来源，不把新增输入类型延后到首版之后。

退出条件：前台刷新或关闭不会丢任务，返回页面可以看到结果；一次提交只产生一个账务事件，失败不会无限重试。

## 阶段 3：完善与封闭测试

产物：直链导入、我的作品、取消、对账、删除及到期清理、预算开关、错误提示和监控。

邀请小规模测试用户，以真实任务统计成功率、身份保持、动作关联、耗时、成本及下载率。只依据实测结果开放模型、规格和并发，不做未经测试的供应商自动切换。

退出条件：核心质量达标，关键异常和安全边界通过，已有生成任务在服务重启、回调重复和网络故障下可恢复。

## 验收场景

| 类别 | 关键场景 | 通过条件 |
| --- | --- | --- |
| 正常创作 | 猫/狗照片 + 本地视频或合法直链 | 生成可播放 MP4，参数与确认摘要一致 |
| 输入来源矩阵 | 宠物图片、宠物视频、舞蹈视频 × 本地上传、HTTPS URL，含混搭 | 每一种来源可预览、校验和提交；宠物视频选帧正确且不替代舞蹈参考 |
| 模型目录 | Text 分类中的 Gemini、Video 输出分类 | 下拉菜单来源正确，非 Gemini 文本模型与仅视频输入模型不能混入 |
| 上游接口映射 | output_modalities、arch、完整分页、视频专用字段 | 不使用 category=Text/Video、不漏分页、不将专用响应强行按通用 schema 解析；空值不充作全能力 |
| 视频参考有效性 | 不同视频模型与实际提供方 | 不支持参考视频或会忽略参考的路由不以动作迁移模式开放 |
| 选择与切换 | 修改任一模型、下架、缓存失效、API 篡改 | 参数重验与旧报价失效，不静默换模型；已创建任务保留原模型快照 |
| 提示词链路 | 基础模板 → 所选 Gemini 再加工 → 所选 Video 模型 | 两次调用准确匹配用户选择；下游使用经校验的最终提示词，失败不绕过或换型号 |
| 目录异常 | 加载失败、空列表、无兼容模型 | 有独立状态和重试入口，无虚构模型或未披露外部服务回退 |
| 用量与费用 | 正常、重试、失败、费用延迟和字段缺失 | 页面显示真实输入/输出/总 token 与 credit；不重复、不混用应用额度、不以 0 代替未知 |
| 用量权限 | 查看他人的任务用量或应用 OpenRouter 账号余额 | 访问拒绝，只返回当前任务拥有者的明细 |
| 动作质量 | 同宠物不同舞蹈，同舞蹈不同宠物 | 参考变化影响动作，主体特征保持；满足 AI 评分门槛 |
| 媒体边界 | 超限、损坏、伪造 MIME、多主体、超短片段 | 明确提示，不发生无意义付费调用 |
| 选段 | 起止时间、边界时长、旋转视频、移动端操作 | 服务端处理与用户选择一致，不裁错片段 |
| 链接 | 分享页、登录页、404、超时、重定向 | 可解释失败，保留其他输入并引导本地上传 |
| 网络隔离 | 内网、元数据地址、IPv6 变体、DNS 重绑定、大文件 | 在下载与解码资源上限内拒绝，无内网访问 |
| 登录与归属 | 未登录上传、跨用户访问资产或任务 | 提交前认证，访问逐次校验，不能越权获取文件 |
| 断线与恢复 | 刷新、离开、会话到期后重登、Worker 重启 | 任务继续且状态可恢复，不再次创建付费请求 |
| 幂等与并发 | 双击、同键重放、重复队列事件和回调 | 一个实际生成任务，一次预留与结算 |
| 不确定结果 | 提交超时但供应商已受理 | 进入对账，不自动重新付费生成 |
| 失败账务 | 分析失败、供应商失败、产物取回失败 | 费用政策正确执行，用户看到退款或待确认状态 |
| 取消竞争 | 点击取消时任务恰好开始提交 | 不能一边显示已退款一边继续无追踪执行 |
| 产物校验 | 失效下载地址、损坏输出、回调伪造 | 不标假成功，回调验签且可恢复下载 |
| 删除 | 运行中删除、迟到回调、旧下载链接 | 立即撤销应用访问，异步删除，明确短期链接残余窗口 |
| 到期 | 原始素材先过期、作品后过期 | 再生成要求重传，下载入口按真实保留状态显示 |
| 费用控制 | 额度不足、过期报价、日预算达到上限 | 拒绝新付费任务，已有任务继续被追踪 |
| 无障碍 | 键盘、屏幕阅读器、减少动态效果、小屏 | 可完成上传、选段、确认与下载，错误可发现 |

开发时针对状态机、权限、幂等、账务、网络导入写有实际防错价值的单元或集成测试；用一条受控真实生成流程做端到端验证。不要用大量截图或组件实现细节测试替代真实视频质量评估。

## 主要风险与处理

| 风险 | 对策与产品后果 |
| --- | --- |
| 人类舞蹈无法迁移到猫狗 | 阶段 0 先验证；必要时限制动作复杂度，或明确改成灵感生成 |
| 主体变形、身份漂移 | 收紧照片及片段条件，用人工盲评门槛控制上线 |
| 生成耗时与成本过高 | 短片、低并发、内测额度和硬预算；依据实测选择输出规格 |
| 网页视频无法导入 | 清楚区分网页和媒体直链，始终提供本地上传入口 |
| 供应商失败但费用已产生 | 预留、对账、幂等；透明费用政策和应用成本缓冲 |
| 模型更新导致回归 | 固定配置版本，重新验证代表样本，控制切换 |
| 素材超期或泄露 | 私有存储、短期访问、归属检查、清理任务和供应商条款核验 |

## 暂定决策与需要用户以后确认的事项

以下默认值已足以完成本次设计；不将它们当作用户已批准的付费采购或真实发布授权。

| 决策 | 当前提案 | 确认时机 |
| --- | --- | --- |
| 视觉与命名 | 爪爪舞台 / PawGroove，暖白 + 紫色 | 高保真设计前 |
| 效果取向 | 趣味轻拟人化，优先保留宠物身份 | 核心样例验证时 |
| 用户范围 | 中文、猫狗、单主体 | 封闭测试前 |
| 参考来源 | 本地文件与 HTTPS 媒体直链 | 若要扩展指定平台，另评估官方授权接入 |
| 宠物输入 | 图片或视频，本地与 URL 均支持；视频选代表帧 | 已明确纳入 MVP |
| 提示词模型 | 下拉选择 OpenRouter Text 分类中的 Gemini 系列 | output_modalities=text 与 arch=Gemini 已核验；实时列表和权限待实测 |
| 视频模型 | Video 分类结合 /videos/models 补充能力，原生 /videos 执行 | 目录和生成接口已核验；逐项验证参考素材与路由后才可选 |
| 用量展示 | 结果页显示 OpenRouter token、实际 credit、结算状态 | 上游字段及单位在实施前核验 |
| 登录 | 预览免登录、提交前邮箱验证码 | 认证实现前 |
| 预算与服务商 | 尚未指定，不估造具体价格 | 任何付费实验或采购前 |
| 部署与数据区域 | 尚未指定 | 服务商和数据条款确定前 |
| 输出规格 | 默认 5 秒、720p、9:16、无声 | 模型验证后按可实现规格更新 |
| 商业化 | 先邀请内测、额度限制，无套餐和支付 | 质量、成本稳定后 |
| 音乐、公开分享 | 首版不含 | 独立扩展需求确定后 |
